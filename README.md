# 善通寺市ジュニアバレーボールクラブ 公式サイト

`index.html` 1ファイルで完結する公式サイトです（CSS・JSも同ファイル内）。
`manifest.json` と `sw.js` を同じフォルダに置くとPWA（ホーム画面追加）に対応します。

## フォルダ構成

```
zentsuji-junior-volley/
├── index.html      … サイト本体（これをそのまま公開すればOK）
├── admin.html      … 管理者用の編集画面（パスワード保護つき）
├── data.js         … サイトの中身（お知らせ・予定・選手・リンクなど。admin.htmlで編集）
├── manifest.json   … PWA設定
├── sw.js           … オフラインキャッシュ用の簡易Service Worker
└── assets/         … ロゴ・アイコン・写真を置く場所（現在は空）
```

`admin.html` は検索エンジンにインデックスされないよう `noindex` を設定していますが、URLを知っている人は
誰でもページ自体は開けます（パスワードを知らないと中の編集画面には入れません）。より厳重に隠したい場合は、
ファイル名を `admin.html` から推測されにくい名前に変更しても構いません。

## すぐに変更してほしい項目（Instagram・地図・フォームなどのリンク）

`admin.html`の「基本設定・リンク」タブから編集するのが最も簡単です（下記「管理者用ページ」参照）。
直接ファイルを編集したい場合は、`data.js` 冒頭の `CONFIG` オブジェクトを書き換えてください。

```js
const CONFIG = {
  teamName: "善通寺市ジュニアバレーボールクラブ",
  instagramUrl: "",     // InstagramのURL
  googleMapsUrl: "",    // 体育館のGoogleマップ共有URL
  applyFormUrl: "",     // 見学・体験申込用Googleフォーム
  contactFormUrl: "",   // お問い合わせ用Googleフォーム
  contactEmail: "",     // 問い合わせ用メールアドレス
  venueName: "",        // 体育館名
  venueAddress: "",     // 住所
  joinTime: "",         // 活動日時（例：毎週土・日 9:00〜12:00）
};
```

未入力の項目はボタンを押すとお問い合わせセクションへ移動するようになっているため、
リンク切れにはなりません。

## 写真の差し替え

現在、写真部分はすべてグラデーションのプレースホルダー（仮画像）になっています。
実際の写真をご用意いただき次第、以下を差し替えてください。

- **ヒーロー背景**：`#heroPhoto` の `style.backgroundImage`（`index.html` 内のJS）
- **ABOUT / JOIN US の写真**：`.about-photo` / `.join-photo` の `background` を `background-image:url(...)` に変更（`index.html` 内のCSS）
- **NEWS・GALLERY・選手写真**：`admin.html`の各タブで画像URLを入力するか、`data.js`内の`newsData` / `albums` / `members`の`img` / `photo`にファイルパスを設定

写真は `assets/` フォルダに入れて、相対パス（例：`assets/photo01.jpg`）で指定してください。

## 管理者用ページ（admin.html）でコンテンツを更新する【推奨】

コーディング知識がなくても更新できるよう、パスワード保護つきの管理者ページ `admin.html` を用意しています。

1. ブラウザで `admin.html` を開く（公開後は `https://あなたのサイト/admin.html`）
2. パスワードを入力してログイン（初期パスワード：`volley2026`）
3. 左メニューから「お知らせ」「活動予定」「大会・試合結果」「選手紹介」「活動写真」「チームの特徴」「基本設定・リンク」を選んで内容を編集する（入力中の内容は自動でブラウザに下書き保存されます）
4. 右上の「data.js をダウンロード」を押す
5. ダウンロードした `data.js` を、GitHubリポジトリの `data.js` に **上書きアップロード**する（リポジトリ画面で `data.js` を開き、鉛筆アイコン「Edit」→ 中身を全部削除して貼り付け、または「Add file → Upload files」で上書き）

数分後、公開サイトに反映されます。

### ⚠️ このパスワード保護の限界について（重要）

`admin.html` のパスワードは、**関係者以外がうっかり編集画面を開かないようにするための簡易的な鍵**です。
このサイトはサーバーを持たない静的サイトのため、たとえ第三者がパスワードを見破って管理画面を開けたとしても、
「ダウンロードボタンでファイルを手元に保存できる」だけで、公開中のサイトを実際に書き換えることはできません。
**本当の意味でのセキュリティは、GitHubリポジトリへの書き込み権限を誰に渡すか、で決まります。**
リポジトリの共同編集者は信頼できる方だけに限定してください。

### パスワードを変更したい場合

`admin.html` 内の以下の行にあるハッシュ値を、新しいパスワードのSHA-256ハッシュに置き換えてください。

```js
const ADMIN_PASSWORD_HASH = "b256cbf46e1aac221f5f4b6d91ec3cea9b657c86b9d6801be7ab1a9e5bc67212";
```

ハッシュ値の作り方が分からない場合は、Claudeに「admin.htmlのパスワードを『新しいパスワード』に変更して」と
依頼していただければ、該当箇所を書き換えます。

### 選手情報の公開・非公開について

選手紹介の各データには「公開する」チェックボックスがあります。チェックを外すとサイト上には表示されません
（個人情報保護のため、デフォルトでは選手データを1件も入れていません。保護者の同意が取れた選手から順に
`admin.html` で追加してください）。

## `data.js` を直接編集する方法（上級者向け）

`admin.html` を使わず、`data.js` をテキストエディタやGitHub上で直接書き換えることも可能です。
以下のJavaScript配列・オブジェクトを編集してください。

| セクション | 変数名 |
|---|---|
| 基本設定・リンク | `CONFIG` |
| お知らせ | `newsData` |
| 活動予定 | `scheduleData` |
| 大会・試合結果 | `matchData` |
| 選手紹介 | `members` |
| 活動写真 | `albums` |
| チームの特徴 | `features` |

## favicon / アプリアイコン

現在は仮のSVGアイコン（ロゴ完成前の代替）を使用しています。ロゴが完成したら、
`assets/` に以下のファイルを用意し、`index.html` の `<head>` 内のリンクを差し替えてください。

- `assets/apple-touch-icon.png`（180×180）
- `assets/icon-192.png`（192×192）
- `assets/icon-512.png`（512×512）
- `assets/ogp-image.jpg`（1200×630／SNSでシェアされた時に表示される画像）

## 今後の拡張（本格的な管理画面・データベース化）について

現在の `admin.html` は、パスワードでうっかり編集を防ぎつつ、`data.js` をダウンロード/コピーして
手動でGitHubにアップロードする「手軽な運用」を想定した仕組みです。

更新頻度が上がってきた場合や、「編集したら自動でサイトに反映される」「複数人がそれぞれのアカウントで
ログインして編集する」といった本格的な管理画面が必要になった場合は、**Supabase** または **Firebase**
への移行を想定した構造にしてあります（`data.js` の配列をデータベースのテーブルに置き換えるだけで
対応できます）。その際は以下のような対応になります。

1. Supabase/Firebaseにテーブルを作成（news / schedule / matches / members / albums）
2. 本物のサーバーサイド認証つき管理者ログインを作成
3. `index.html` 内のデータ取得部分を、`data.js` の読み込みからAPI呼び出しに置き換え

このタイミングでの移行作業もご相談いただければ対応可能です。

## 公開方法（例）

このフォルダをそのまま以下のようなサービスにアップロードすれば公開できます。

- レンタルサーバー（FTPで `zentsuji-junior-volley` フォルダの中身をアップロード）
- Netlify / Vercel / GitHub Pages（フォルダをそのままドラッグ＆ドロップ、または連携）

独自ドメインを設定する場合は、各サービスの案内に従ってDNS設定を行ってください。
